# 🦂 Scorpion Hunter Game

Sichqonchani boshqarib, sahrodagi haqiqiy chayonni harakatga keltiring va hasharotlarni ov qiling!

## 🎮 O'yin Haqida

Bu interaktiv **Canvas** asosidagi mini-o'yin bo'lib, unda siz sichqoncha yordamida realistik chayonni boshqarasiz. Chayon sahro bo'ylab yuradi, oyoqlari tabiiy harakatlanadi, dumi ko'tarilgan holda turadi va uchidagi zaharli nishi yashil rangda porlaydi.

## ✨ Xususiyatlar

- 🦂 **Realistik Chayon** — Ichi bo'yalgan, gradient ranglar bilan to'liq anatomiya: bosh, ko'zlar, qisqichlar, 8 ta oyoq, segmentlangan tana va egilgan dum
- 🏜️ **Sahro Muhiti** — Qumoq rangli gradient fon va qum zarralari
- 🪲 **O'ljalar (Hasharotlar)** — Ekranda paydo bo'lib, qochib yuradigan mayda hasharotlar. Ular chayondan qochadi!
- ⚡ **Hujum Mexanikasi** — Sichqonchani bosib zaharli zarba bering! (Yaqin masofada hasharotlarni yo'q qiladi)
- 🏆 **Hisob Tizimi** — Nechta o'lja tutganingiz ekranda ko'rsatiladi
- 🦵 **Tabiiy Harakat** — Oyoqlar yurish animatsiyasi, silliq kuzatuv va fizik zanjir harakati

## 🕹️ Qanday O'ynaladi

1. `index.html` faylini brauzerda oching
2. **Sichqonchani harakatlantiring** — chayon ergashadi
3. Hasharotlarga yaqinlashing
4. **Sichqonchani bosing (click)** — zaharli zarba!
5. Ko'proq hasharotlarni ovlang va yuqori ball to'plang! 🎯

## 🛠 Texnologiyalar

- **HTML5 Canvas** — butun grafika
- **Vanilla JavaScript** — o'yin logikasi
- **CSS3** — interfeys dizayni
